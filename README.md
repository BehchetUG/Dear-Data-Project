# Dear Data Project

Data Collection for the Dear Data Project will begin on the week starting from the 12th of October.

My plan is, after consolidation, is to gather around 35 data points within this week. It will help with building a strong foundation to the project before the end of the half-term. 

Due to how early I am starting, it will also give me more than enough time to code and visually represent my data using Processing, while taking inspiration from the Dear Data Project and the way those two girls presented theirs.

My actual data points will be about my screen time usage, whether that is on my phone or on my laptop, and it will be further broken down into the top 5 most used or watched apps that make up a percentage of that daily screen time.

These data points will be displayed in an unique, creative way that shows the progression of my data. There will also be a title, the days, time and a key to assist the person viewing my Project by removing any confusion, and enhancing understanding.
